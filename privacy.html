Privacy Policy

App: SSH Server Monitor
Effective date: 2026-05-19 · Last updated: 2026-05-19

This app ("SSH Server Monitor") helps users monitor Linux SSH servers and websites. We collect as little data as possible and keep sensitive credentials on device.

1. Information We Process

  • SSH connection settings: host, port, username, and display name that you enter.
  • SSH credentials: passwords and private keys are stored in iOS Keychain when you save a server.
  • Website monitor settings: monitored URLs, tags, and notes used for status checks and widgets.
  • Diagnostic data: latency, status code, SSL info, and DNS/header analysis generated by your own checks.
  • Purchase state: Pro entitlement state is synced via Apple App Store and RevenueCat.

2. How We Use Data

  • Run SSH and HTTP checks requested by you.
  • Render widgets and optional background refresh updates.
  • Show alerts and weekly reports.
  • Enable or disable Pro features based on purchase status.

3. Third-Party Services

  • RevenueCat: used only for purchase and entitlement handling. See RevenueCat Privacy Policy.
  • Apple services: App Store purchase processing and standard iOS platform services.

4. Data Storage and Security

  • Credentials are stored in iOS Keychain.
  • App and widget shared data use App Group: group.com.oxygenhu1.serverpulse.
  • We do not run our own backend to collect your server credentials.

5. Children

This app is not directed to children under 13.

6. Your Choices

You can delete saved servers/websites in the app and uninstall the app at any time.
